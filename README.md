# TCHESS
TCHESS 是一款支持 uci 和 ucci 协议引擎的跨平台象棋界面程序，具有功能：
+ 加载引擎
+ 对弈
+ 分析
+ 棋谱
+ 连线
+ 开局库

使用说明请参考 [MANUAL.md](https://github.com/sojourners/public-Xiangqi/blob/master/MANUAL.md)，访问 [Release](https://github.com/sojourners/public-Xiangqi/releases) 下载最新版本。

# 运行环境和依赖
+ JDK 21  
+ JavaFx 23
